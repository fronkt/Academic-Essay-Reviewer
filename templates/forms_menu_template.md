# Forms Menu Template (`forms` mode)

Output of `forms` mode. It is a **menu, not a draft**: patterns drawn from what other applicants actually
wrote, each with a fill-in-the-blanks skeleton the writer adapts with their own material. Nothing here is
pre-filled with the writer's biography (IRON RULE, Checkpoint 5), and the conventional answer is always
shown first. A creative option sits next to it, never in place of it.

Source every example and form statement from `references/creative_forms.md` (a school's general guidance
may also come from `university_guidance.md`), carrying its tag
(OFFICIAL / OFFICIAL-ADJACENT / PRESS-QUOTED / PUBLISHED-EDITORIAL / PRACTITIONER / COMMERCIAL / CRAFT /
COMMUNITY), its access grade (READ / READ-WF / SECONDHAND), and its URL from §11 or the §7 table. An
option with no real example says so: `Real examples: none found (searched: …)`. Mark the catalog's own
synthesis *(S)* and anything this run inferred *(inferred)*.

**How the mode runs.** One merged pass, not independent reader reports. The context analyst's forms card
is the header. Craft work (the §2 tests) goes into each block's "Why it can work here" and "Fails when".
Institutional work (school stance, does it answer the prompt) goes into SCHOOL STANCE and "Answers the
prompt?". No ratings, no verdict. Pause to confirm the header with the user only if a field was inferred
rather than given: the prompt text, the limit, the portal, or the school.
WHAT THE PROMPT TESTS is always a judgment and never triggers a pause.

## 2. Options by risk level

**If the prompt requires a form** (FORM REQUIRED = yes), the levels measure distance from the plain
version of that form, per the table in `creative_forms.md` §3. The list or note itself is never counted
as the risk; cite the §3 table in the block's catalog field; and the plain-prose test applies to the
bend, not to the assignment.

Give 1–3 patterns per level. Choose by evidence strength first, then by fit to the limit. Name the
catalog patterns you did not select in one line per level. Each pattern uses this block:

```
  Move:        [what the pattern does, in one sentence]
  Why it can work here: [the form–content fit this prompt allows; the §2 tests it passes. With no
                 draft or profile, T1 (fit to this writer) is "the writer's call"; say so]
  Skeleton:    [fill-in-the-blanks outline; general; slots in brackets, e.g.
                 line 1: [the ordinary object], stated plainly
                 line 2–4: [three uses of it, each more specific than the last] …]
  Real examples: [described, not copied; year; tag; access grade; URL]  |  none found (searched: …)
                 (Every READ-WF quote in the catalog was confirmed verbatim on 2026-09-23 and may be quoted.)
  Evaluation:
    Words/chars:   [arithmetic at the EXACT limit: what the scaffolding (headings, labels, repeated
                    frames) costs and what is left for content; give a range where symbols or numerals
                    make the count uncertain]
    Portal:        [survives as written | needs plain-text fallback | breaks — why]
    Answers the prompt? [yes | only if … | risk of reading as a non-answer — name the sentence that must
                    carry the literal answer. For an open prompt: does it still reveal a person?]
    Evidence:      [strong | moderate | weak | none] per creative_forms.md §0, plus the catalog's own wording
  Fails when:  [the specific gimmick failure for this pattern, from the catalog entry or §8]
```

Carry the catalog's *(S)* marker on any line that is the skill's own synthesis rather than a source.

### LOW — fresh framing
Same prose shape as the conventional target, but an unexpected angle, entry point, or answer.

### MEDIUM — structural device
The essay is still recognizably an essay, but its shape carries meaning: segmented, braided, a
repeated frame, a list spine, a countdown, reverse order.

### HIGH — format break or sideways reading
A borrowed form (recipe, letter, glossary, lab report, FAQ, transcript …) or a reading of the prompt
that answers it from an angle the prompt did not anticipate. Withhold a HIGH option only when the portal
cannot carry it (§6) or the school's published stance rules it out (§5). Otherwise show it, with the
evidence grade stated plainly and T1 left to the writer.

## 4. The plain-prose test (for whichever option the writer picks)

Before committing to a form, the writer answers (test numbers from `creative_forms.md` §2):
1. **What does the form say that plain prose can't?** If nothing, it is costume (cliché taxonomy #21).
   (T0 is this skill's own test, not a quoted source.)
2. **Is the form true to the writer?** (T1: a recipe essay from someone who cooks; a list from a
   list-maker.) **Does it echo the subject?** (T3)
3. **Does one sentence still answer the prompt literally?** Point to it. (T9)
4. **Does it survive the portal and the limit?** (T7, T10; §6 and the arithmetic above.)
5. **Is there still a why?** Every Johns Hopkins commentary that praised a form credited what it
   revealed (§1.2). College Essay Guy's "So what?" test (`craft_frameworks.md` §1.4) applies inside any form.

## Rules

- **General, not tailored.** Skeletons have slots, not the writer's facts. If the writer supplies
  material and asks to see it in a form, that is `redraft` mode (L5, facts ledger, ceiling), not this one.
- **No fabricated examples.** Every "real example" traces to a catalog entry with a tag and a §11 URL.
  Community reports are labelled self-reported, with outcome claims attributed to the poster.
- **Honest ceilings.** If the evidence for a HIGH option is only community anecdote, say "weak evidence"
  in the block; do not let a vivid example stand in for a base rate.
- **Certification-bound prompts** (STS, anything under an L0 ceiling): the menu may still be shown, since
  it is general and contains no prose for the applicant to submit. (No skeleton is ever pre-filled in
  this mode; for a certification-bound prompt, `redraft` of the writer's own material is also off.)
