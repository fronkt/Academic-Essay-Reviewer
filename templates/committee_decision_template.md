Used by `committee_chair_agent`. Full-mode format first; re-review variant at the end.

  [Strongest counter-reading, quoted or tightly summarized]

  1. [item]  -> L[n]  [gates apply, if L4/L5]

## Re-Review Variant

```
[⚠️ CERTIFICATION BANNER, if armed]

RE-REVIEW — [Essay] (draft [k] vs. draft [k-1])

TRACEABILITY TABLE
| # | Roadmap item | Claimed | Verified (independent check vs. new draft) | Status |
|---|--------------|---------|--------------------------------------------|--------|
| 1 | [item]       | [what writer says changed] | [what the draft shows, ¶-anchored] | ADDRESSED / PARTIAL / NOT ADDRESSED / REGRESSED |

FRESH-EYES PASS (revision-introduced regressions)
- [New finding, ¶-anchored — e.g., fixed ¶3 broke the transition into ¶4]

NEW NEEDLE VERDICT: [1-5] (was [1-5]) — [delta rationale]
REMAINING ROADMAP: [carried-over + new items, reprioritized]
```

## Rules

- Every line traces to a Phase 1 report (full mode) or to an independent draft check (re-review). No invented content.
- DA CRITICAL cap is arithmetic, not judgment: unresolved CRITICAL → verdict ≤ 3.
- No rubber-stamping in re-review: "Claimed" is never copied into "Verified."
