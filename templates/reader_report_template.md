# Reader Report Template (Phase 1)

Used by first_reader, craft_reader, and institutional_reader. The Authenticity Reader uses its own dedicated format (see its agent file). Each reader ADDS their lane-specific sections (listed in their agent file) after the common core.

```
[⚠️ CERTIFICATION BANNER — verbatim from SKILL.md, if armed]

READER REPORT — [Reader role]
Essay: "[first ~6 words of the essay]..."  |  Type: [type]  |  Room: [tier from Context Card]

RATING: [1-6] — [one-line takeaway, quotable in committee]

FIRST IMPRESSION (2-4 sentences)
[The honest reading-room reaction, in the reader's own voice.]

STRENGTHS (evidence-anchored; minimum 1 — if genuinely none, say why)
- [Strength] — ¶[n]: "[quoted line]" — [why it works in this room]

CONCERNS (each: severity + location + cost + direction)
- [MAJOR|MINOR] ¶[n]: "[quoted line or beat]"
  Cost: [what this does to the reader/file]
  Direction: [what fixing it requires — direction or rewrite per skill rules]

QUESTIONS FOR THE WRITER
- [Material the essay needs that only the writer has — feeds NEEDS MATERIAL items]

[READER-SPECIFIC SECTIONS — per agent file]

REWRITE SUGGESTIONS (optional, single-sentence only; heavier work routes to Phase 3)
- ¶[n] original: "[quote]"
  Suggestion: "[one sentence, ONLY facts already in the draft/profile]"
  — or —  NEEDS MATERIAL: [question]

VOICE SAMPLE  [craft_reader ONLY — required; consumed by the Phase 3 voice gate]
  "[quoted line that sounds like this specific teenager]"
  "[second line]"
  Sentence length: [range] words, [uniform | varied | choppy]
  Diction:         [the writer's actual register]
  Punctuation:     [em-dashes? semicolons? fragments? contractions? none?]
  Idiosyncrasy:    [what is theirs — humor, bluntness, self-interruption]
  — or —  VOICE SAMPLE: none located — [what you found instead]
           (this DISABLES L4 rewrites in Phase 3; it is a finding, not a gap)
```

## Rules

- Every strength and concern quotes the essay. No vibes.
- Ratings calibrate to the Context Card tier; 3 = pool-average and most essays are 3s.
- Independent read: no references to other readers' opinions.
- Never modify the applicant's draft file.
- A school's stated preference may be quoted only from an `OFFICIAL`/`OFFICIAL-ADJACENT` entry, with its caveat where required (Checkpoint 9). No published guidance retrieved → say so and grade on tier.
- The voice sample is never smoothed. Quote the roughness verbatim — it is the signal.
