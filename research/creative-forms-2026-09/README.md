# Research notes: creative forms (2026-09-23)

Raw research behind `references/creative_forms.md`. It came from four parallel research strands and one
adversarial verification pass. Each note keeps every URL, its access grade (READ / READ-WF / SNIPPET),
its speaker tag, and a "searched, not found" log. Agents do not load these files; they are the audit
trail for refreshing or challenging the reference.

| File | Strand |
|---|---|
| `A_official.md` | University-published "essays that worked", officer commentary, base-rate tallies, official welcome/warning statements |
| `B_practitioner_craft.md` | College Essay Guy and other named practitioners; creative-nonfiction forms (hermit crab, braided, segmented, abecedarian, footnoted, second person) |
| `C_reddit.md` | r/ApplyingToCollege and r/collegeresults via the Arctic Shift archive: self-reported outcomes, cautionary tales, former-AO comments |
| `D_portal_formatting.md` | What each application portal does to line breaks, styling, and characters |
| `V_refute.md` | Adversarial verification of `creative_forms.md` (quotes, attributions, dates, tallies) |
| `T_dryrun.md` | First trial run of `forms` mode (Stanford list prompt, Common App prompt 7) and its 30-item friction log, which drove the v1.3.0 fixes |
| `T2_dryrun.md` | Second trial run (Stanford list again, UC PIQ 1) after the fixes: mandated-form handling and UC's stance worked; 32 smaller items, the substantive ones fixed |

Page copies were not archived (third-party copyright). Quotes in the notes are at most about 25 words.
